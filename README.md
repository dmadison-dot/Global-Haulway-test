# Global Haulway - Milestone 2

## 1. Accessibility Fixes (WAVE Error Prevention)
* I added an `alt` attribute to the image on the Projects page to ensure screen readers can describe the visual content to visually impaired users.
* I selected a high-contrast color palette (neon green `#D6FA6B` against dark backgrounds `#141414`) to prevent low-contrast errors and meet WCAG AA visual standards.
* I included the `lang="en"` attribute in the root `<html>` tag on every page to ensure assistive technologies apply the correct English pronunciation rules.

## 2. Visual Design (Gestalt Principles)
* **Proximity:** I used the principle of proximity by applying a strict 8px spacing system, intentionally grouping related form elements (like a label and its respective input box) close together so users instantly perceive them as a single connected unit.
* **Similarity:** I used the principle of similarity by styling all of the service cards on the Projects page with identical borders, background colors, padding, and typography, which visually signals to the user that these items share the same level of hierarchy and function.
